## 已知实现边界（与设计的偏差/取舍）

1. 组织私钥的"管理员副本"改为 ECIES(管理员公钥)（等价安全域，任意管理员可代恢复）——见 03 文档。
2. 语义向量不建 ANN 索引（百级文档精确扫描足够，维度可配置）。
3. 服务端挑战-应答存储的是 authProofKey（HKDF(authKey)），无法反推 encKey——见 03 文档第 0 节。
4. OCR（图片）与组共享的批量 UI 已留接口/实现，图片 OCR 默认关闭。
