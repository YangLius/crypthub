## 已知实现边界（与设计的偏差/取舍）

1. 组织私钥的"管理员副本"改为 ECIES(管理员公钥)（等价安全域，任意管理员可代恢复）——见 03 文档。
2. 语义向量不建 ANN 索引（百级文档精确扫描足够，维度可配置）。
3. 服务端挑战-应答存储的是 authProofKey（HKDF(authKey)），无法反推 encKey——见 03 文档第 0 节。
4. OCR（图片）与组共享的批量 UI 已留接口/实现，图片 OCR 默认关闭。

## 真实环境联调记录（2026-11-10）

环境：远程 PostgreSQL 18.4（47.109.143.246:5651/crypthub）+ 智谱 API（glm-4-flash / embedding-3@512 维）
本地：uvicorn + worker + fakeredis（无 docker 开发方案，scripts/dev_redis.py）

**新增偏差（联调确认，已实现）**：

1. 目标库无 pgvector 扩展 → embedding 存 `real[]`，向量检索改为两阶段
   （先取向量 Python 侧精确余弦取 top-8，再取整行 RRF 融合）——检索质量不变，
   部署不再要求 pgvector（compose 可用普通 postgres:16）。
2. 目标库无 Redis → 本地开发用 fakeredis TCP 服务器；worker 循环对
   TimeoutError/ConnectionError 做了免疫（瞬时错误不杀守护进程）。

**端到端冒烟（scripts/smoke_e2e.py，模拟浏览器走全链路）25/25 通过**，
覆盖：引导→建号(组织密钥)→挑战登录→错误密码拒绝→上传→去重 409→
worker 索引(真实 embedding)→兜底扫描(3 条待认领)→混合检索→AI 问答(真实 LLM+引用)→
解锁→建条目(AAD)→reveal 解密闭环→lock 拦截→第二用户→跨用户 403→审计全覆盖。

**联调发现并修复的真实 bug**（均为单元测试盲区，仅在真实 DB/并发下暴露）：

| # | 缺陷 | 修复 |
| --- | --- | --- |
| 1 | schema.sql 用 `#` 注释（PG 不支持） | 改 `--` |
| 2 | asyncpg 预处理语句不支持多命令一次执行 | init_schema 按分号拆分逐条执行 |
| 3 | setup SELECT 漏 `setup_token_expires` / `role` 字段（KeyError） | 补全列 |
| 4 | bytea 列绑定 b64 字符串（org_offline_salt/salt_*/rk_salt） | 解码为 bytes，去掉无效 CAST |
| 5 | 队列/会话 JSON 序列化 UUID 对象 | str() 归一 |
| 6 | worker 在事件循环内调 asyncio.run（embedding 同步入口） | 直接 await embed_texts |
| 7 | secrets 授权校验 UUID vs str 集合比较 | uid 归一化 str |
| 8 | SQLAlchemy text() 误解析 `::uuid[]` 为绑定参数 | 改 `CAST(:ids AS uuid[])` |
| 9 | 检索阶段二数组 cast 误用 uuid[]（chunks.id 是 bigint） | 改 bigint[] |
| 10 | **set_unlocked 锁定写回旧值（锁从未生效，安全 bug）** | 写回前先改状态 |

## 功能追加：多级目录（2026-11-11）

文档区与密钥区均支持多级目录归类（超出 v1.1 设计范围的增强）：

- 新增 `folders` 表：`parent_id` 自引用多级，`kind` 区分 doc/secret 两棵独立树；
  同目录同名唯一（表达式唯一索引），层级上限 10 级，移动禁止进入自身子树（环检测）。
- **文档目录**：全员共享树，`documents.folder_id` 归档；删除目录时子目录级联删除，
  文档自动回到未归档（FK ON DELETE SET NULL）。
- **密钥目录**：每人私有树（`owner_id`），归档位置存在授权行
  `secret_grants.folder_id` —— 同一条密钥 owner 与被授权人可各自归档，互不影响。
- API：`GET/POST /folders`、`PATCH/DELETE /folders/{id}`、
  `PATCH /documents/{id}`(folder_id)、`PATCH /secrets/{sid}/folder`；
  前端两页共用 FolderTree 组件 + 目录选择弹窗，列表为客户端过滤。
- 运维注意：**改动 schema（加列/表）后需重启 worker**——长连接 asyncpg 的
  预编译语句缓存会因 schema 变更失效（首次访问该语句的文档索引会失败一次，
  SQLAlchemy 随后自动整体失效缓存，自愈）。
