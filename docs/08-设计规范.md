# 08 · 设计规范（Astryx 设计系统）

> 2026-11-12 起生效：**秘枢前端所有页面的设计与美化统一使用 [Astryx](https://github.com/meta/astryx)
> 设计系统**（Meta 开源，174 个可访问组件 + 主题系统 + agent CLI）。
> 后续一切新功能、新页面、新组件都必须使用 Astryx，不再手写按钮/输入框/弹窗等基础控件。

## 已接入

- `@astryxdesign/core@0.7`（组件库）+ `@astryxdesign/theme-neutral`（主题）+ `@astryxdesign/cli`（dev，agent 工具）
- React 已升级至 **19**（Astryx 的 peer 要求）
- `src/main.tsx`：全局导入 `reset.css` / `astryx.css` / 主题 CSS，`<Theme>` + `<LinkProvider>` 包裹全应用
- `src/astryx-themes.ts`：CLI 生成的主题注册（勿手改）
- `frontend/AGENTS.md`：CLI `init` 写入的组件索引与工作流（**AI/人开发前必读**）
- `src/components/ui.tsx`：Button/Modal/Badge/Empty/Spinner/ConfirmModal/PromptModal 等
  已全部改为 Astryx 组件的兼容封装，全部页面自动继承新视觉

## 开发工作流（来自 AGENTS.md，摘要）

1. 新页面从模板开始：`npx astryx build "<想法>"` → `npx astryx template <name> <path>`
2. 用组件前先读文档：`npx astryx component <Name>`
3. 改现有页面：保留页面骨架，在区块内加 Astryx 组件/块
4. 交付前自检：`npx astryx doctor --built <dir>`
5. **规则**：布局用组件不写 `<div>`；密集数据用 Table/List 而非卡片堆叠；
   Badge 只用于计数/状态；样式先 props 后 token（`var(--color-*)` 等），禁止裸 hex/px；
   品牌色走主题（`astryx theme add <slug>`），不写 `:root` 覆盖
