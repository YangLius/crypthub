# 内部使用规范（员工须知）

> 本规范替代对外服务条款，是使用本系统的前提。注册完成即视为已阅读并同意。

## 1. 主密码与恢复码

- **主密码**只有你自己知道，系统任何人（包括管理员）都看不到、也帮不了你找回。
- **个人恢复码**在开号时只展示一次。忘记主密码时，它是你找回自己密钥的唯一自助途径。
- 两者都丢失且没有管理员协助时，你的数据**不可恢复**——这是零知识架构的代价，请务必把恢复码抄在纸上放到安全的地方。

## 2. 服务端能看到什么

- **密钥区**：服务端能看到你给条目起的名字、项目、环境、标签；**看不到任何内容**（用户名/密码/令牌/备注全部加密）。
- **文档区**：文档正文在服务端是明文（已脱敏）。上传前系统会在浏览器里扫描疑似凭据，由你确认替换后才上传——**请配合确认弹窗，不要随手跳过**。
- 不要把生产凭据粘贴到 AI 对话里；系统会拦截，但请不要依赖拦截。

## 3. 管理员的恢复能力（必须知情）

- 管理员在**留下审计记录并通知你**的前提下，技术上可以代为查看/恢复你的密钥条目（用于你忘记密码、离职交接等场景）。
- 每次组织恢复都会：记录操作人与理由 → 写入审计 → 给你发通知。
- 公司约定：恢复仅在上述场景下使用，禁止窥探。

## 4. 共享与撤销

- 共享给同事后，**撤销授权收不回对方已经看过的内容**。
- 撤销敏感条目的授权后，请立即**轮换真实密码**——这是唯一有效的回收手段。

## 5. 离职交接

- 离职前必须完成交接：管理员会把名下条目重新授权给接手人。
- 涉及敏感条目（生产数据库、云账号等）**一律轮换真实密码**——技术手段挡不住"看过的人把密码记走"。

## 6. 日常行为

- 密钥区"查看"时的二次输码（解锁）是你本机的本地验证，过期自动锁定；离开工位请锁定。
- 不要把本系统的链接和自己的主密码借给他人使用；每个动作都有审计记录。
- 发现异常（被共享了不知名条目、收到不明恢复通知）立即联系管理员。
